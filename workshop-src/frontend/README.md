# Customer Portal Frontend

React 기반 고객 포털 UI입니다.

## Purpose

This package renders the customer portal landing page and contains the API URL helper used by the UI layer.

## Commands

Run from the repository root:

```powershell
npm install
npm test --workspace frontend
npm run start:frontend
```

Build the frontend:

```powershell
npm run build --workspace frontend
```

## Configuration

The frontend currently uses `http://localhost:8080/api` as its API base URL.
